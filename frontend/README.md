# Yogeswaran V — Frontend Web Application

**Live URL:** [https://yogeswaran-v-portfolio-2005.vercel.app](https://yogeswaran-v-portfolio-2005.vercel.app)

Frontend client for Yogeswaran V's software engineering portfolio, engineered with React 19, Vite, Tailwind CSS v4, and Lucide React.

## Features
- **Theme System:** Modern high-contrast design with system-aware dark and light mode toggle.
- **Local-First Resilience:** Instant static JSON fallbacks with asynchronous background API updates.
- **Performance Optimized:** Route code-splitting with `React.lazy`, optimized asset delivery, and WCAG AA contrast compliance.
- **Verified Showcase:** Strictly audited project specifications, coursework, and competitive programming profiles.

## Setup
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
